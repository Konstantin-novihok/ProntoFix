# TrueNAS, Intel HD 530, перевод и озвучка

## Проверка драйвера

Intel Core i3-6100T содержит Intel HD Graphics 530. На TrueNAS SCALE Intel GPU обычно доступна через встроенный драйвер ядра, отдельный установщик от Intel чаще всего не нужен. В Shell выполните:

    lspci -nnk | grep -A3 -Ei 'VGA|Display|3D'
    ls -l /dev/dri/
    dmesg | grep -Ei 'i915|drm|firmware' | tail -80

Ожидаемые признаки — kernel driver i915 и устройство рендеринга вроде /dev/dri/renderD128. Точное имя зависит от версии TrueNAS и BIOS.

В TrueNAS SCALE откройте Apps → Settings и включите GPU support, если этот пункт доступен. При настройке приложения включите Passthrough available (non-NVIDIA) GPUs. После запуска контейнера проверьте, что /dev/dri доступен внутри него. Не устанавливайте случайные пакеты ядра и не добавляйте i915.force_probe без прямого указания в системном журнале и проверки версии ОС.

## Что ускоряет GPU

Стандартная сборка faster-whisper/CTranslate2 поддерживает CPU и NVIDIA CUDA, но не использует Intel HD 530 как CUDA GPU. Поэтому распознавание остаётся на CPU. Intel iGPU потенциально ускорит отдельные операции FFmpeg через VA-API, если доступны совместимые драйверы и кодеки. Это независимые возможности.

После передачи устройства проверьте внутри контейнера наличие /dev/dri, а затем при установленной vainfo выполните vainfo и ffmpeg -hide_banner -hwaccels. Если аппаратный путь не работает, оставьте FFmpeg на CPU.

## Перевод и голос

Сервер использует Argos Translate. Для каждой пары исходный язык → целевой язык должна быть установлена подходящая локальная модель; список из 16 языков в интерфейсе сам по себе не означает, что все возможные языковые пары уже установлены. Перед массовой обработкой проверьте реальные направления.

Для синтеза нужен Piper и совместимая голосовая модель. Укажите путь в переменной окружения PIPER_MODEL. Проверьте лицензию и наличие голоса нужного языка. Без голосовой модели распознавание, TXT и SRT продолжат работать.

Первый дубляж формирует одну голосовую дорожку из всего переведённого текста и заменяет ею звук видео. Это тестовый вариант, не профессиональная синхронизация: длина отдельных фраз не выравнивается по таймкодам. Для точного дубляжа потребуется озвучивать сегменты отдельно и подгонять их длительность.

## Файлы до 500 ГБ и безопасность

Клиент отправляет куски по 8 MiB, API собирает файл на диске и не читает весь видеофайл в память. На постоянном dataset требуется место под исходник, WAV, текст, субтитры и итоговый MP4; свободного пространства ровно 500 GB недостаточно для исходного видео в 500 GB. Текущая версия не гарантирует автоматическое продолжение загрузки после закрытия браузера.

API пока не имеет авторизации. Оставляйте его в доверенной локальной сети, не пробрасывайте порт напрямую в Интернет и не загружайте конфиденциальные видео до внедрения аутентификации и HTTPS.
