# ProntoFix

ProntoFix — локальная система для работы с видео и техническими материалами: серверная обработка и Android-клиент.

## Структура проекта

- `server/` — FastAPI API, обработка задач и конфигурация сервера.
- `web/` — веб-интерфейс, доступный с компьютера или телефона.
- `mobile/` — место для Android-приложения ProntoFix; клиент разрабатывается отдельным этапом.
- `docs/` — инструкции по настройке TrueNAS, распознаванию, переводу и озвучиванию.
- `tests/` — место для автоматических тестов.
- `transcribe.py` — прототип распознавания речи из видео.
- `docker-compose.yml` — пример запуска через Docker Compose.

## Возможности серверного прототипа

- Загрузка видео частями и очередь задач.
- Распознавание речи через faster-whisper на CPU в режиме int8.
- Перевод через Argos Translate при установленных языковых пакетах.
- Сохранение текста и субтитров TXT/SRT.
- Опциональная озвучка через Piper и замена звуковой дорожки через FFmpeg.
- Редактирование распознанного и переведённого текста.

## Важные ограничения

Это ранний прототип, а не готовый production-сервис. Перед использованием в сети нужно добавить аутентификацию и проверить ограничения загрузки, обработку ошибок и тесты. Не публикуйте API напрямую в интернет. Для перевода нужны языковые пары Argos Translate; для озвучивания — голосовая модель Piper. Длинные видео требуют значительного свободного места для временных файлов.

## Разработка

1. Проверять исходный код и тесты перед изменениями.
2. Не хранить пароли и токены в репозитории.
3. Адрес сервера задавать конфигурацией, не зашивать его в мобильное приложение.
4. Старый репозиторий `IA` остаётся резервным источником; дальнейшая работа ведётся в `ProntoFix`.
