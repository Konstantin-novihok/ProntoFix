# ProntoFix

ProntoFix — проект обслуживания и ремонта с отдельными компонентами для сервера и мобильного приложения Android.

## Структура

- `server/` — серверное приложение, REST API, конфигурация и работа с базой данных.
- `mobile/` — Android-приложение ProntoFix.
- `tests/` — автоматические тесты.
- `docs/` — архитектура, запуск и инструкции по развёртыванию.

## Принципы разработки

1. Перед переносом кода проверять исходный проект и известные ошибки.
2. Не хранить секреты и пароли в репозитории.
3. Проверять изменения тестами и сборкой перед выпуском.
4. Серверный адрес задавать конфигурацией, а не зашивать в код.

## Статус

Начальная структура проекта. Сервер и Android-клиент будут добавляться отдельными этапами после анализа исходного кода и требований.
