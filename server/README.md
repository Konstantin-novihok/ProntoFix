# ProntoFix Server

Здесь будет серверная часть ProntoFix: REST API, аутентификация, база данных, конфигурация и инструкции запуска.

## Требования к реализации

- Конфигурация через переменные окружения.
- Проверка входных данных и единый формат ошибок API.
- Хеширование паролей и безопасная работа с токенами.
- Автоматические тесты API.
- Документация по локальному запуску и развёртыванию.
